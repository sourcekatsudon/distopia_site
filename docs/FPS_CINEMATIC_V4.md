## 改修の方針と範囲

赤を敵・侵食・施設警告、シアンから青を武器・主人公HUD・シールドへ割り当て、主要な金属面は低彩度にした。輪郭と面の分節を先に直し、Bloomは局所的な発光の補助に使う。

Three.js r160とWebGLを維持した。WebGPU移行、大量の外部3Dモデル、実行時の生成AI API呼び出しは追加していない。通常のレストランサイトからFPSは遅延読み込みし、スマホでは軽量FPS、PCでは高品質描画を初期選択する。

## ARC-RG7 / BLUE REQUIEM

大きなレシーバーは、可変断面のスーパー楕円ロフトから生成した。丸い外装を重ねていた初稿は画像批評で不合格となり、一体の暗い主構造と段差のある側面装甲へ整理した。長い二本の電磁レールを独立して見せ、クランプの反復を減らした。

主要なメッシュ階層は以下のとおり。

```text
ARC-RG7
└─ recoil cradle
   ├─ faceted receiver / 主レシーバー・側面装甲
   │  └─ capacitor cartridge / 引き抜くエネルギーセル
   ├─ reciprocating breech / 往復スライド
   ├─ split rail assembly / 二本の伸縮レール
   ├─ accelerator collars / 回転する電磁加速器
   ├─ cooling leaves / 展開する冷却フィン
   ├─ hands / 支持する手・前腕
   └─ muzzle / エネルギー流・閃光・局所照明
```

固定部品は材質ごとにまとめ、回転・伸縮・開閉する機構は独立した階層を保つ。黒染め金属、ガンメタル、チタン、セラミック、ゴムの材質を分けた。広い金属面で傷が三角形状に強く出たため、武器の主装甲には控えめなブラシ状粗さを使っている。

可動状態は `IDLE / PRECHARGE / CHARGING / FULLY_CHARGED / FIRING / RECOIL / COOLING / RECOVERY`。約95msの予備動作、チャージに追従する遅れ付き伸長、射撃の反動、熱の減衰に従うフィン開放を別の時間定数で動かす。一斉に全機構が停止する動きは避けた。

呼吸は従来と同じ周期で、左右位置0.003→0.015、上下位置0.006→0.030、ピッチ0.003→0.015、ロール0.002→0.010と振幅を**5倍**にした。カメラの揺れを無効にすると呼吸も止まる。

銃は右手で保持し、左手が支持する。リロードでは銃を傾け、左手がセルへ伸び、セルの引き抜き・交換・装着を行う。空になった時の自動リロードとRキーによる明示的な交換を維持した。交換中は射撃できず、セルが固定された後にエネルギーが戻る。

銃上の残量表示は数字ではなく、独自の発光する図形8個。残量に従って消え、交換中は消灯し、装着完了に合わせて再点灯する。

頭部と四肢は断面ロフト、装甲は面取りした押し出し形状を主体とする。胸の大きな無地の平板は、独立レビューの指摘を受け、暗い凹部、リブ、限定した金属縁に分節した。膝にも暗い内側パネルを設けている。顔のシアン装飾を除き、赤い眼と胸コアを脅威の識別点にした。

ダメージ領域と倍率を維持したまま静的部品をバッチ化し、装甲・頭・コア・四肢を区別する。被弾時の装甲剥離とキル時の分離部品は、既存の軽量な速度・重力・回転処理へ接続した。完全なラグドール物理ではない。

## 発砲・敵弾・シールド

プレイヤーのビームは白い芯と青い外周を分け、ShaderMaterialで視線方向、軸方向の揺らぎ、時間と寿命による減衰を表現する。発射後に残る単色の円筒だけで終わらせていない。マズルフラッシュ、加速器、スライド、反動、局所照明を連動させる。

銃口近くの衝撃波が画面全体を横切る問題は、連番批評で検出した。半径と寿命を抑え、早く減衰する細い残光へ修正した。命中点には青い電撃、暖色と青の火花、局所的な発光、装甲片、ヒットマーカーを出す。パーティクル・ビーム・リング・閃光・電撃は上限を設けたプールで再利用する。

敵弾は、赤白い発光芯、赤い外殻、後方に伸びる暖色の尾で構成する。低品質32発・通常64発のプールを共有Geometry/Materialで管理する。弾道の区間と遮蔽物を照合し、壁で消えた弾はシールド演出とプレイヤー被弾処理へ進まない。

シールド残量があるとき、接近した弾の方向にだけ球面の六角模様が浮かび、青い波紋が短時間で広がる。球面全体を常時発光させない。反射光跡には暖色の芯と横方向への偏向を加えた。

**反射は表示専用。** 元の弾による通常のシールド・HP計算を維持し、反射表示には敵との衝突・ダメージ処理を持たせていない。元の弾の見た目を消して、反射の表示を別プールで動かす。

## 材質・施設・支配者

`material-kit.js`はValue Noise、FBM、方向性のある傷、Voronoi系の摩耗、カーボン織りなどから、初期化時にCanvasで材質をベイクする。高品質512px・バランス256px・軽量128px。毎フレームの再生成は行わない。

チタン、黒染め金属、ガンメタル、塗装鋼、腐食鋼、カーボン、セラミック、ゴム、発光材、露出骨格を共通化し、施設側の警告塗装を合わせて使う。粗さ・法線・金属成分などを材質別に変えた。品質ごとの参照数付きキャッシュを共有し、各モデルは必要なMaterialを複製して所有する。最後の参照を破棄した時に共有テクスチャも解放する。ランタイム自体も共有材質への参照を保持し、支配者からFPSへの切り替えで全参照が一度ゼロになって再ベイクする待ちを避けた。画質を変えて再開始する場合は必要な品質へ参照を取り直し、終了時にはこの参照も解放する。

施設は既存の配管、梁、壁面分割、床パネル、制御盤、コンテナ、原子炉、蛇行通路を維持し、金属表面の粗さと微細な凹凸を追加した。搬入口の40枚の扉は共有InstancedMeshへまとめ、個別の開閉動作を保った。通過済み側からの増援と、遮蔽物による射線分断も維持している。

支配者にはプリーツを持つ独自BufferGeometryの重いマントを追加した。肩から床へ広がる面、折り目、裾の不均一さを作り、炭素系の表面を抑えた光沢で照らす。玉座、長い腕、爪、赤い眼と胸コア、ケーブルと深い柱列を組み合わせた。低速のカメラ移動と断罪文は既存の導入演出を維持している。

WebGL2または浮動小数点描画先が利用できない場合も直描画へフォールバックする。高品質のMSAAは実際に利用可能なRGBA16Fのサンプル数を照合する。

PCではまず世界を深度付きHDR描画先へ描き、局所的な遮蔽を最大28%の暗さに制限して加える。これは軽い画面空間の接触AOであり、完全な物理的遮蔽ではない。武器は別レイヤーで深度をクリアして後から描き、世界の深度によるAOが手前の武器へ誤って重ならないようにする。Bloomは各辺1/4の描画先を2方向にぼかし、ACES・色空間変換、弱いVignetteとFilm Grainで合成する。色収差は被弾・命中イベント時に限定する。

反射は生成した環境マップによるPBR反射を使う。SSRや高負荷なボリューム積分は導入していない。奥行きには既存の指数Fogと蒸気・微粒子を使う。

スマホでは左スティック移動、右ドラッグ照準、FIRE、CHARGE、ジャンプ、操作、リロード、ポーズを表示する。Pointer Lockを必要とせず、移動・照準・射撃を別の指で併用できる。各操作の所有ポインターを限定し、チャージ取消時は発射せずに溜め状態も消す。縦横回転、ポーズ、終了時には入力状態を整理する。

画質変更時は光・影・DPR・ポスト処理をすぐに切り替える。現在の効果品質と生成済みアセット品質は開発用の統計でも区別する。造形・テクスチャ・粒子プールなどを完全に切り替えるには再開始が必要なため、設定画面に説明と「この画質で最初から」ボタンを設けた。

[uno-com-escada](https://github.com/viktorkav/uno-com-escada)と、同リポジトリの[反復制作記録](https://github.com/viktorkav/uno-com-escada/blob/main/astra/PROCESSO.md)を、手続き的な造形・材質ベイク・計測・独立批評の一般的な着眼点として研究した。ソースコード・メッシュ・テクスチャはコピーしていない。本実装はThree.js上の独自ロフト、Canvas材質生成、独自の描画処理で構成した。

## 残る制約

- 手袋の指、敵の肩・腰の荷重経路、支配者の平たい肩板と肘掛けには、Moderateの造形上の改善余地がある。
- 破壊は主要部品の分離を確認できるが、胴体が急に消える点があり、完全な重量感のある倒壊やラグドールではない。
- 深度AOは世界の描画に適用する軽量方式。武器内部のすべての隙間を物理的に遮蔽するものではない。
- 高品質はHDR描画先・深度・MSAA・シャドウの負荷を持つ。実機スマホの性能保証はしていない。
- 通常サイトの軽量性はFPSモジュールを読み込まない条件で確認した。FPS開始時には材質ベイクと初回シェーダー構築の待ち時間がある。
- 最終Previewの認証状態と本番反映は既存の運用に従う。本報告だけをもって本番反映済みとはしない。
