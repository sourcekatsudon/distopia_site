# 閲覧20秒で「バレた。逃げろ。」

通常サイトで表示中の閲覧時間を合算し、約20秒でハッキング演出を始める。PC・スマホ共通。ページ移動でも時間を引き継ぎ、1秒未満の短い滞在もpagehide時に記録する。非表示タブとBFCacheで離れていた時間は加算しない。

同じタブでは自動開始は1回。帰還・終了後に繰り返し襲わない。自動演出を明示的にOFFにした設定を尊重し、OSの「動きを減らす」設定では初期OFF。サイト演出設定で手動開始・FPS直行も選べる。`?protocol=off`は自動開始を止める。`?protocol=play`は待たずに全導入、`?protocol=quick`はFPSへ直行する。

以前はPCの60〜120秒、スマホ初期OFFだった。既存タブの未発火タイマーも20秒へ移行し、発火済み状態は保持する。

ローディング、ハッキング後の接続表示、戦闘準備の見出しを「バレた。逃げろ。」へ変更。全導入は維持し、戦闘の開始操作はクリック／タップで行う。スマホの操作パネルが導入のスキップを覆っていた問題を修正し、演出・準備中は操作パネルを隠す。

検証：構文とNodeテスト22スイート通過。実時間でのページ移動試験はPC11項目、スマホ12項目通過し、記録した自動発火時刻はPC20.98秒・スマホ20.80秒。全ハッキング、支配者、新しい文言、同タブの再発火防止を確認。スマホ操作58項目も通過。スマホはChromiumのタッチエミュレーションであり、物理端末の性能測定ではない。
