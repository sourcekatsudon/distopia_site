# Chicken House — ESCAPE PROTOCOL: ASCENSION

通常サイトからの侵食演出を保ち、地上の成長・遮蔽戦闘から宇宙艇による脱出までを実装した。通常のレストラン閲覧ではFPS／Three.jsを読み込まない。

[最新ブランチのPreview](https://chicken-house-git-feature-glitch-protoc-38fa17-photors-projects.vercel.app) · [PR #2](https://github.com/sourcekatsudon/distopia_site/pull/2)

[実画面ギャラリー・録画](fps-captures/ascension/index.html)。固定展示画像は実際のWebGL出力だが、装備・敵・場面をデバッグで選んでおり、通常進行を省略している。録画と固定展示を、手動完走や実機スマホの性能実証として扱わない。

## 武器成長とリロード

LV1とLV2は専用モデル、LV3は既存のARC-RG7を使う。LV4／5は同じ主構造へ補助リアクター、位相リミッター、開閉装甲、流れるエネルギーを増設した。LV5には拡大した開放型の銃口も加えた。主武器の呼吸、手による保持、セル交換、図形残量表示を維持する。

| LV | 装備 | 容量 | リロード | チャージ |
| --- | --- | ---: | ---: | --- |
| 1 | ARC-P1 / SERVICE PISTOL | 12発 | 1.5秒 | なし |
| 2 | ARC-L2 / RAPID LASER | 24発 | 1.8秒 | なし |
| 3 | ARC-RG7 / BLUE REQUIEM | 100単位 | 1.8秒 | 貫通・対装甲 |
| 4 | ARC-RG7 EX | 100単位 | 1.9秒 | 貫通数増加・連鎖 |
| 5 | ARC-RG7 Ω | 120単位 | 2.0秒 | 高出力・貫通／連鎖強化 |

弾薬の自然回復を廃止した。空になると自動リロードし、Rでも交換できる。交換途中には補充せず、ロック完了後に容量分へ戻す。射撃予備動作とリロードの競合を防ぎ、スマホの自動射撃で目標を失った場合は予約弾を取り消して戻す。

モジュール4個ごとに進化し、16個でLV5となる。同じ報酬IDを再取得しても加算せず、上限も16個。獲得した成長は直ちに保持し、死亡時には最新のLVとモジュールを維持して、約160mごとの位置チェックポイントから再開する。破壊状態・報酬取得・使用済み補給の台帳もラン内で保持する。補給はEで使い、各地点1回のみ。ページ再読み込みをまたぐ永続保存ではない。

## 7種の敵と遮蔽

| 敵 | 戦闘上の特徴 |
| --- | --- |
| Scout Drone | 浮遊して射撃する斥候 |
| Execution Soldier | 予備動作を見せて撃つ標準兵 |
| Rush Assassin | 接近して近接攻撃する高速機 |
| Sniper Unit | 長い予告から高威力・高速弾を撃つ |
| Shield Guardian | 向いている側のシールドで吸収。側面や対装甲攻撃が有効 |
| Heavy Enforcer | 大型装甲と連続弾 |
| Suppression Turret | 固定位置からの制圧射撃 |

出現は場所に結び付けた遭遇で管理し、後方増援は一部の地点へ限定した。敵の全滅を必須にするキル数ゲートはなく、遮蔽を使った回避や前進も可能。短距離の一斉出現だけで進行させない。

敵弾はプレイヤー、シールド、遮蔽物それぞれの交点距離を比べて、最初の衝突を採用する。レビューで見つかった「背後の壁が弾を先に消し、手前のプレイヤーに当たらない」不具合は、この比較と純粋関数の回帰テストで修正した。

## 実際に壊れる施設

貨物、バリア、発電機、制御パネル、破壊可能な壁の5種に、`INTACT → DAMAGED → CRITICAL → DESTROYED`の4状態を持たせた。装甲の脱落、内部の発光、破片と残骸だけでなく、同じ衝突体をプレイヤー・射撃・敵AIが共有する。

破壊すると衝突体を無効化し、敵のナビゲーションも更新する。壁を壊した穴は実際に通れる。敵弾も遮蔽物へダメージを与えるため、同じ場所に隠れ続けると遮蔽が失われる。発電機の爆発は周囲の敵・破壊物へ作用し、見た目だけの爆発ではない。破壊台帳は区画の読み込み解除後も残り、戻った時に新品へ復元されない。

[破壊の検証結果](fps-captures/ascension/destruction.json)では、LV1の通常弾による貨物破壊、敵タレット弾による遮蔽破壊、破壊地点の再読み込み、発電機の爆風を含む8項目が通過した。

## 2.65kmの施設から宇宙へ

32区画を配置し、折れ曲がる推奨走行ルートは**2657.56m**。端末、連絡通路、貨物処理、熱交換、保安設備、原子炉を抜け、最終格納庫へ進む。近傍だけを生成・保持し、実測した常駐上限はHighで4区画、Lowで3区画。施設全体を一度に描画しない。

格納庫の宇宙艇へ搭乗すると、三人称のレールシューティングへ切り替わる。横移動でも機体を画面内で追いやすいよう、カメラの追従率と距離を調整した。通常の飛行時間は180秒。そのうち最後の8秒がワープで、通常空間の惑星・追撃物を消し、高速の光跡へ移行する。ボス撃破を脱出条件にはしない。追撃を振り切った後は短い静寂を挟み、通常のChicken Houseへ自動復帰する。

## スマホと通常サイト

スマホはLow／直描画を初期選択し、左右2スティックで移動と照準を同時操作する。照準に入った、遮蔽されていない敵へ自動射撃する。LV1／2では`BREAK`で環境を通常射撃し、LV3から`CHARGE`へ切り替える。利用できないチャージ操作を低LVに表示しない。

タッチ取消、回転、ポーズで軸・チャージ・予約射撃を整理する。所有していない指の解除でチャージを発射しない。Pointer Lockは不要。スマホではジャンプとスプリントを省き、宇宙でも2スティックと自動射撃を使う。

通常サイトの遅延読み込みを維持し、FPSを開始しなければゲームのモデル生成や描画は発生しない。スマホの実機速度を検証したものではなく、PCブラウザーの画面・タッチエミュレーションで動作を確認した。

[balance.json](fps-captures/ascension/balance.json)。731／997／42の順。実際のAI・弾・衝突を使い、ゲーム時間を固定刻みで進めた。HP回復デバッグや強制死亡は使っていない。

| 方策 | 条件 | 結果 | 被弾回数 | リロード／撃破 |
| --- | --- | --- | --- | --- |
| A | LV1、固定正面へ射撃、静止 | 55.1／55.2／92.8秒で死亡 | 29／28／39 | 9／9／15回、各0体 |
| B | LV1、固定正面へ射撃、左右移動 | 約120秒、全試行生存 | 9／14／10 | 各20回、各4体 |
| C | LV1、敵追尾照準、遮蔽と覗き撃ち、明示的交換 | 約120秒、全試行生存 | 1／1／0 | 各27回、各4体 |

## 地上から帰還までの通し確認

統合担当による最終通し試行は、理想的な弱点照準、区間ごとの12秒観察テンポ、実際のE操作による補給を使う自動操作。実AI・物理・弾薬・成長を通し、HP回復デバッグは使っていない。ゲーム時間を進めた計測であり、人間が同じ実時間で完走した記録ではない。

| 到達点 | 開始からのゲーム時間 |
| --- | ---: |
| LV2 | 77.00秒 |
| LV3 | 294.20秒 |
| LV4 | 500.45秒 |
| LV5 | 752.10秒 |
| 地上終了 | 約14分48秒 |
| 宇宙・ワープ終了 | 約17分48秒 |

地上は死亡0、140体撃破、16モジュール、502射撃、40リロード、被弾1回。宇宙180秒では21体撃破、859射撃、被弾0。その後のサイト自動復帰まで確認した。

区間死亡率は、この単一bot試行の観測として全区間0。一般プレイヤーの死亡率や平均クリア時間は推定していない。全滅は必須でないため、最短ルートを急いで進むプレイはこの観察テンポより短くなり得る。

最終証跡は[full-run.json](fps-captures/ascension/full-run.json)。地上集計は887.90秒、全体集計は1067.75秒。集計段階の異なるタイマーに0.15秒の差があるため、主表示は秒単位に丸め、精密値は元JSONを参照する。

## 実測性能

同じGTX 1080 Ti／ANGLE D3D11、1920×1080、約30秒のPC計測。遭遇中の敵は最大4体。高密度の全場面・全機種を代表する保証ではない。

| フレーム時間 中央値 | 16.6ms | 16.6ms |
| フレーム時間 p95 | 29.7ms | 26.1ms |

## 検証とレビュー

- Nodeの13スイートが通過。追加した`armory.cjs`は武器5段階×High／Lowの有限値・更新中のGPU資源増加なし・所有資源の正確な破棄を確認。`space-flight.cjs`は両画質で180秒、21体撃破・860射撃・被弾0の飛行fixtureを完走し、放置では35.65秒・12被弾で死亡すること、終了時のカメラと環境の正確な復旧を確認した。これは上記ブラウザー通し試行の859射撃とは別の試行。
- [デスクトップ統合57項目](fps-captures/ascension/integration.json)、[スマホ操作58項目](fps-captures/ascension/mobile.json)、[破壊8項目](fps-captures/ascension/destruction.json)が通過。成長・重複取得・死亡再開・衝突・ナビ更新・飛行・ワープ・通常サイト復帰を含む。
- 実際の敵の近接攻撃で死亡するケースも8項目確認し、LV2・4モジュール、位置チェックポイント、満タンのHP／シールド／24発、報酬重複防止が再開後も成立した。
- 既存の武器15項目／発光18項目／終了・復帰16項目も最終再実行が通過。新規起動を3回繰り返した各時点でGeometry 34／Texture 21が一致した。資源個数の安定性の確認であり、VRAMバイト量の測定ではない。
- 貨物の4段階画像を独立Criticが確認し、Majorなし。CRITICALでは内部の赤い発光が見えるよう改善した。LV1／2／3の交換画像も追加した。
- 画像のみの独立Criticで、ワープ中に通常空間の惑星が残るMajorを検出・修正し、再確認を通過した。MinorはLV4／5の差が控えめ、駐機艇の暗部、追撃機が小さめな点。
- Antigravity CLI 1.5.12の`claude-sonnet-5-5-medium`をバランス顧問として使用し、SUCCESSを確認。内部では武器・施設／戦闘・宇宙飛行を分担し、別のレビュー担当が統合差分を確認した。採否・統合・検証はCodexが担当。

## 既知の制約

人間によるプレイ統計、一般的な死亡率・クリア時間、実機スマホの性能は未測定。難易度比較は3シードに限る。成長や破壊台帳は現在のタブのラン内だけで保持し、localStorageによる進行保存はしない。初回描画とストリーミング生成のヒッチ、LV4／5の造形差、駐機艇の暗部などには改善余地がある。本報告のPreviewは本番反映を意味しない。
