# Chicken House — GLITCH PROTOCOL / FPS ESCAPE

通常のレストランサイトから、架空の侵入警告・機械支配者・施設の端末への引き画を経て、実際に操作できる3D FPSへ移行する追加体験。既存の32品のメニュー、検索、スライドショー、太陽系店舗マップは維持している。

## 始め方

- 通常閲覧：アクティブな閲覧時間60〜120秒で1セッションにつき原則1回。非表示中は計時しない。
- フッターの「サイト演出の設定」：自動演出を無効にする／手動で開始する／標準・軽量品質を選ぶ。
- 動きを減らす設定またはスマートフォンでは、自動演出は初期状態で無効。手動開始は可能。スマートフォンでは軽量な通信演出とPC向けの案内を表示する。
- `?protocol=1`：警告から即時開始。
- `?protocol=play`：導入を省略して、開始ボタンのある戦闘準備画面へ。
- `?protocol=off`：そのページの自動演出を停止。
- `&fpsdebug=1`：ローカルなQA APIを公開。実プレイでは不要。QA APIはサーバーや他ユーザーに接続しない。

どのフェーズでも「演出を終了」で通常サイトへ戻れる。ゲームは勝手にフルスクリーンにせず、カメラ・マイク・位置情報・通知の権限も要求しない。警告はChicken House内のSFフィクションであり、実際の端末の逆探知や攻撃ではない。

## 操作

|操作|入力|
|---|---|
|移動|WASD|
|視点|マウス。ドラッグ操作モードでは左ボタンを押しながら移動、矢印キーも使用可|
|通常射撃|左クリック・長押しで連射|
|チャージ貫通射撃|右ボタンを長押しして放す|
|ジャンプ|Space|
|スプリント|Shift|
|隔壁・ゲート制御盤の操作|E|
|ポーズ|Esc、ポインターロック解除、非表示イベント|

「戦闘モードを開始」はユーザー操作でPointer Lockと音声を有効にする。許可できない場合はドラッグ操作を選べる。右クリックのコンテキストメニュー抑制はゲーム画面の操作中だけ。ポーズ中に音量・ミュート・カメラの揺れ・品質を変更できる。動きを減らす設定ではカメラの揺れは初期無効。

## ゲーム進行

想定は5〜8分。5区画で合計96体の防衛ユニットと戦う。一定間隔で増援が到着し、区画の敵を排除すると隔壁・封鎖が解除される。

|区画|構成・進め方|敵数|
|---|---|---:|
|TERMINAL ROOM|先ほどのサイトを映した端末。初戦を終えて隔壁をEで開く|6|
|SECURITY CORRIDOR|配管と隔壁の通路。全増援を排除し封鎖を解除|14|
|REACTOR HALL|巨大な原子炉、左右のルート、ランプで上がれる2mの通路、重装甲敵|22|
|LOCKDOWN|交互の遮蔽壁と複数方向の出現点。全増援で封鎖解除|26|
|ESCAPE GATE|最終戦後、出口手前の左側の青い制御盤をEで操作してゲートへ|28|

敵は浮遊ドローン、人型執行兵、重装甲エンフォーサー。距離・射線・経路・ストレイフ・被弾硬直を持つ。HPゼロはリトライ可能。脱出成功後はサイトへ帰還し、一時的に `SUBJECT ESCAPED` の痕跡を表示する。

武器は **ARC-RG7 BLUE REQUIEM**。通常射撃と太い貫通チャージ、回転コイル・冷却ファン・スライドカバー・ピストン・冷却フィン・流れる発光ライン・機械腕を持つ。レール、部位別Raycast、ヒットマーカー、装甲の破片、火花、衝撃波と合成音でフィードバックする。破片は重力・回転・床での跳ね返りを持ち、一定時間残る。

## 技術・ファイル構成

静的HTML/CSS/JavaScript。ビルドやバックエンドは不要。ゲーム用Three.jsとES Modulesは、演出の開始時にのみ遅延ロードする。通常サイトの最初の表示でFPSコードやThree.jsはロードしない（会社ページの既存太陽系マップは従来どおり独立）。

|ファイル|責務|
|---|---|
|`js/glitch-sequence.js`|不規則な横走査、36枚の危険色ポップアップ、500msの赤コード上書き|
|`js/site-protocol.js`|閲覧タイマー、セッション、設定、警告Overlay、遅延ロード、サイト復帰|
|`css/protocol.css`|警告、字幕、HUD、ポーズとフォールバックのスコープ付きスタイル|
|`js/fps/runtime.js`|描画とフェーズ、戦闘、出現、HUD、ゲート、勝敗、資源寿命の統括|
|`js/fps/simulation.js`|固定シード、円とAABB、射線、NavGraph、AI、ダメージ、進行、高さ|
|`js/fps/world.js`|5区画、配管、隔壁、原子炉、ランプ、端末、InstancedMesh|
|`js/fps/materials.js`|擦り傷・錆・警告帯・端末のCanvasTexture、共有材質|
|`js/fps/weapon.js`|レールガン、機械腕、充電・反動・可動機構|
|`js/fps/actors.js`|3種の敵、玉座、機械支配者、ケーブルと変形する布|
|`js/fps/effects.js`|上限付きビーム、粒子、衝撃波|
|`js/fps/audio.js`|Web Audioの合成音、音量、ミュート、同時音数制限|
|`js/fps/input.js`|入力、短いキータップのキュー、Pointer Lock、解除|
|`vendor/three.module.js`|Three.js 0.160.1のローカルコピー。MITライセンス同梱|

既存ページの変更はゲームの小さな統合スクリプトと設定ボタン用スタイルの追加が中心。`js/solar-system.js` は変更していない。

## 生成と外部アセット

施設、銃、敵、支配者、布、配管、材質、環境反射、エフェクト、音声は固定プログラムで生成。実行時のAI API呼び出しはない。外部の3Dモデルや大容量音源は使用していない。端末内のサイト画面には既存の商品画像を再利用する。添付参考画像は方向性の参照のみで、3D画面の代わりに表示する方式ではない。

Three.jsの取得元：`https://cdn.jsdelivr.net/npm/three@0.160.1/build/three.module.js`。ライセンス：`vendor/THREE-LICENSE.txt`。ゲーム本体はローカルに同梱し、ゲーム開始時にCDNの稼働を要求しない。

## 上限と後始末

- 敵の同時稼働は標準12体・軽量8体。粒子640／220、残骸160、ビーム24、衝撃波8、効果音20ボイスを上限とする。
- 静的な床・壁・配管はInstancedMeshでまとめ、材質やジオメトリを共有する。
- Pixel Ratioは標準1.5・軽量1を上限とする（実際のDPRが低ければそちらに合わせる）。
- 非表示・Pointer Lock解除でポーズ。終了時はRAF、入力イベント、AudioContext、材質・Texture・Geometry、RendererとWebGL Contextを解放する。
- FPS中は既存ページを一時的にhidden/inertにし、帰還時に元の値へ戻す。既存DOMや太陽系マップを作り直さない。

## 追加調整：サイトから支配者への高速遷移

通常のサイトを見せたまま不規則な赤い横線を走らせ、0.42秒後から警告を42ms間隔で36枚増殖。WARNING / HACKING DETECTED / 危険 / 探知 / 逆探知などが重なり、約2.15秒で上書きを開始する。赤い文字列の列ごとの先端をずらし、画面を上から500msで覆う。3Dライブラリはこの演出開始と同時に先読みし、最後の赤コードを保持したまま支配者の最初の描画を待ち、直接処刑メッセージへつなぐ。遅い接続ではコード画面の保持が延びる場合がある。

モーション削減時は3枚の静かなパネルと短い上書きへ切り替える。高速な全面点滅は使わず、横線の移動・パネルの追加・文字列による上書きで表現する。終了ボタンは常に前面に残る。
