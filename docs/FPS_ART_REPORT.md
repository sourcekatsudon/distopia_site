# Chicken House ビジュアル改修レポート

2026-11-19 / 武器を最初のレビュー対象として実装・撮影。その後、敵・施設・玉座・HUDを統合。

## 方針と実装順

主役は黒い装甲と電光ブルーのレールガン。敵のセンサー、施設の警告、支配者の権威は赤。中間色は鋼色・黒に抑え、金属の縁、隙間、機構と発光を読める構成にした。コンセプト画像を背景として貼る方式ではなく、すべてリアルタイムのThree.js形状・材質・描画で構成している。

1. 武器の箱形レシーバーを撤去し、実画面で4回造形・配置・照明を調整。
2. ユーザーの追加仕様に合わせ、自動/Rセル交換、独自グリフ残量計、両手と呼吸を追加。
3. 武器確認後、3種の機械兵、VFX、工業施設、玉座、HUDを統合。
4. ブラウザで射撃、再装填、5区画の脱出、破棄、低品質設定を確認。

## 武器の部位構成とメッシュ階層

`ARC-RG7 / BLUE REQUIEM → recoil cradle` の下に以下を分離した。

| 部位 | 造形 / 機能 |
| --- | --- |
| faceted receiver | 斜めに切った外装、重なるチタン装甲、開いた上部スパイン、刻印、締結ボルト |
| reciprocating breech | 発砲で独立して後退するスライド、露出した油圧ロッド |
| port / starboard electromagnetic rail | 明確に分かれた二本のレール、セラミック絶縁部、青い導体、中央の空間 |
| accelerator collar 1–3 | 六分割した磁気加速器、銅色の巻線、段ごとに異なる径と回転 |
| terminal accelerator / ballistic muzzle | 四本の先端爪で囲む開放加速器と、実際の発光・射撃位置 |
| capacitor cartridge | カメラ側の大型セル、保護ケージ、端部発光、露出配線 |
| hinged coolant leaf | 左右10枚の放熱葉。発砲後に開き、冷却で閉じる |
| glyph energy annunciator | オリジナルの角形グリフ8個。物理メッシュの発光線が残量に合わせて消灯 |
| armored firing hand / left support hand | 右手でグリップ、左手で前部を支持。左手はセル交換時にセルへ追従 |

固定部品は親グループ内で材質ごとに結合し、可動部だけを分離。Geometry/Materialの生成は初期化時に行い、毎フレーム増殖させない。粗さと微細な傷はプロシージャルテクスチャ。銃と腕は専用の深度パスで描き、壁際で欠けることを防ぐ。照準レイの遮蔽判定はワールド側に残している。

## アニメーションと残量

- アイドル：ゆっくりした呼吸による上下・左右・傾き。コイルの小さな脈動と機構駆動。
- チャージ：導体・セル・コイルが増光、磁気カラーが加速し、レール間隔がわずかに開く。内部のシェーダーで光が後方から先端へ走る。
- 発砲：95msの予備動作後、実際の発射と同時にコイル増光、スライド、反動、閃光。短い残光と放熱葉の開放が続く。
- 再装填：1.8秒。銃を傾ける → 左手がセルに届く → 抜き取り → 画面下で交換 → 差し込み → ロック音とグリフ再点灯 → 構えに戻る。
- 通常弾を撃てない残量で自動交換。チャージ弾のエネルギー不足時も交換を開始。Rで先行交換できる。交換中の再要求は無視し、射撃は停止する。
- 銃本体に残弾の数字は置かない。8グリフは各12.5%を示す。HUDの数値は視認性のため維持。
- 連射で残量が減るよう、射撃後1.1秒は自然回復を待つ。待機後の回復速度は既存の25/秒。空セルは装填完了時に100へ戻る。
- ポーズ中は交換も停止。リトライ時は状態を初期化。揺れを無効にすると呼吸とカメラ揺れを停止する。

## 敵と破壊

| タイプ | 再設計 |
| --- | --- |
| Sentry Drone | 平たい六角シェル、正面の赤レンズ、独立4基の推進部、露出ジンバル銃、回転ローター |
| Execution Soldier | 角形マスクと2つの赤眼、首の脊柱、左右で開く胸装甲と縦長コア、肩・上腕・肘・前腕・骨盤・膝・足を分離。露出した肋骨、ピストン、背部ケーブル、肩ベント |
| Heavy Enforcer | 大きな肩楯、小さな頭、重量脚、背部動力炉と排気塔、片腕の多砲身機構。標準兵の単純拡大にはしていない |

歩行時に肩・首・上腕・肘・脚・膝を連動。被弾で装甲が開き、装甲への非致死命中では実際に板が脱落し、内部骨格を露出する。撃破時は複数部位が回転・落下・跳ね返る。青い放電、金属色の火花、衝撃リングを重ねた。チャージ弾は太さ・閃光・放電規模を増やす。部品は上限160個、粒子640/220個、ビーム24本で制限する。機械兵の重なりを軽減する、衝突を確認した小さな分離処理も追加した。

## 玉座・施設・HUD・画面処理

玉座の背後に三重の途切れた光輪、斜めの支持柱、垂れたケーブル、赤いコード幕、肩の刃状構造、胸部の機構を追加。赤い逆光と冷たい縁の光を使い、55度の画角と遅い接近で機械王を大きく見せる。FPSでは78度に戻す。

施設には追加の壁面区画、ダクト・斜め支持、床グレート、監視機構、機械専用サイネージ、赤い警告灯、セキュリティ端末、浮遊微粒子を追加。食堂端末の表示は維持し、施設奥は監視・制御UIへ切り替えた。既存の配管、巨大炉、蒸気、霧を合わせる。

HUDは細いシアン線、透過パネル、整列した数値と小さな機器識別表示を使用。ヒットマーカーと赤い被弾フィードバックを維持・調整。画面処理は線形HDR → 1/4幅・高さのBloom抽出と2方向ぼかし → ACES/出力変換。弱いVignette/Film Grainを追加し、色収差は被弾・命中時のみ小さく出す。強いグリッチは従来のイベント時に限定。

HDR非対応環境は通常描画へ戻す。標準品質のMSAAはRGBA16Fが対応するサンプル数を実機で確認し、非対応なら無効化。軽量設定はMSAAを外し、DPRと描画先のサイズも更新する。

## 検証と性能

Node：全FPSモジュールの構文、site smoke、FPS simulation、lifecycle、glitch sequence、新規weapon-stateを実行し通過。

ブラウザ：FPS本編25項目、武器15項目、ライフサイクル16項目の計56項目を今回の変更で再実行し通過。5区画・96体を加速QAで脱出まで確認。実際のマウス入力によるチャージとレイキャスト命中も確認した。手動の全編クリア時間を計測したわけではない。

Windows / Chrome 157 / ANGLE NVIDIA GeForce GTX 1080 Ti D3D11 / 1440×1000 / DPR 1 / 標準品質 / 敵12体の原子炉で、190フレーム中先頭10を除外した180サンプル：平均59.998fps、p95フレーム16.9ms。サンプル末尾632 draw calls、97,216 triangles、442 geometries、15 textures。Bloom、武器専用パス、2×MSAA込み。激しい連続爆発の最悪条件ではない。

旧版の別測定は368 draw calls・77,418 trianglesだった。今回の代表場面は描画回数と形状が増えている。画角・敵配置が完全に同一のA/Bではなく、60fps上限でGPUの余力も比較できないため「高速化した」とは評価しない。初期化/終了を3回繰り返したGPU資源数は毎回124 geometries / 14 texturesで増加なし。CPU/GPUの実メモリ量を直接計測したものではない。HDR描画先とMSAAのメモリ・帯域コストは追加される。

## 委任と制約

Antigravity 1.5.11、実機のモデル一覧で確認したClaude Sonnet 5.5 Mediumを、武器の造形レビューとrobots.jsの提案コードに使用。提案専用で元リポジトリへの書込みや外部公開を許可していない。成功ステータスと実出力を確認し、Codexが造形、ダメージ倍率、ドローン高度、バッチ化などを修正して採用。独立したコードレビューで見つかったHDRフォールバック、描画先リサイズ、エネルギー面、HDR形式別MSAAの問題も修正した。

既知の制約：プロシージャルなスタイルで、映画用アセットや実写品質を再現するものではない。手は簡易な手続き形状と追従で、フルスケルトンIKではない。破壊は軽量な部品物理で、剛体ラグドールではない。Firefox/Safari、実機モバイル、HDR非対応GPUの実ハードウェアは未検証（フォールバックの分岐テストは通過）。FPSは従来どおりPC向けでモバイルは案内画面。通常サイトの32品メニュー、削除済み商品、2秒写真スライドショーと遅延読込みは維持。
